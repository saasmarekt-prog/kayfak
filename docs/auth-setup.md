# إعداد المصادقة

المرحلة التالية أضافت عميل Supabase وشاشة تسجيل الدخول والتسجيل واستعادة كلمة المرور، مع استمرار التطبيق في العمل بوضع المعاينة عندما لا تكون متغيرات Supabase موجودة.

## الإعداد

1. أنشئ مشروع Supabase اختباريًا.
2. طبّق migration المرحلة الثانية عبر Supabase CLI.
3. انسخ `.env.example` إلى `.env`.
4. أضف عنوان المشروع والمفتاح العام `anon` أو `publishable` فقط:

```env
EXPO_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=YOUR_PUBLIC_KEY
```

5. أعد تشغيل Expo بعد تغيير متغيرات البيئة.

لا تضع `service_role` أو أي مفتاح إداري في الهاتف. لم يتم ربط الحساب بصفحة الملف الشخصي أو البيانات البعيدة بعد؛ هذه الخطوة تهيئ الجلسة والمصادقة فقط.
