# المحفظة والهدايا والاشتراكات

تضيف migration `0005_wallet_gifts_subscriptions.sql` حساب محفظة بالعملات الافتراضية، ودفتر قيود append-only، والهدايا، والمشتريات، والاشتراكات. لا يستطيع تطبيق الهاتف تعديل الرصيد أو إدخال قيود مالية؛ القراءة فقط متاحة لصاحب الحساب عبر RLS، أما الترحيل فمحصور بخادم الفوترة الموثوق.

تستخدم عملية الهدية `record_gift` مفتاح idempotency وقفلًا على محفظة المرسل. العملية تخصم وترسل وتكتب قيدي الإرسال والاستلام داخل معاملة واحدة. لا تخزن الجداول بيانات بطاقات أو أسرار دفع.

أضيفت Edge Function باسم `billing-webhook` لمسار Stripe؛ تتحقق من توقيع webhook وتقرأ قائمة المنتجات من `BILLING_PRODUCTS_JSON` الموجودة في أسرار الخادم، ثم تستدعي `record_purchase_credit`. ما يزال تفعيل Apple App Store أو Google Play يحتاج adapter مستقلًا للتحقق من إيصالات المتجر. لا تعتمد على `coin_amount` الذي يرسله تطبيق الهاتف.

قبل الإنتاج، أضف اختبارات مالية للتزامن، التسويات، رد المبالغ، النزاعات، حدود الشراء، ومراجعة السجلات. لا تعتبر هذه migration تكامل دفع مكتملًا دون مفاتيح مزود واختبار webhook فعلي.
