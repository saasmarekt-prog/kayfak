# ربط البيانات — المرحلة الحالية

أصبح التطبيق يستخدم Supabase عند توفر متغيرات البيئة:

- `src/features/profile/profileRepository.ts` يقرأ ويحدّث ملف المستخدم عبر سياسة RLS.
- `src/features/discovery/roomRepository.ts` يستدعي `discover_public_rooms` بدل قراءة بيانات الغرف مباشرة من الواجهة.
- `supabase/migrations/0002_profile_discovery.sql` تضيف دالة الاكتشاف، الفهارس، والتحقق من الفئة والصفحات.

## سلوك البيئات

- عند غياب إعداد Supabase: تبقى غرف المعاينة المحلية ظاهرة وموسومة بوضوح بأنها تجريبية.
- عند وجود إعداد Supabase: يستخدم التطبيق نتائج RPC فقط، ولا يعود إلى بيانات تجريبية عند فشل الاتصال؛ يعرض حالة خطأ بدل تضليل المستخدم.
- الدالة تعيد الغرف العامة الحية فقط، وتستبعد الغرف التي حظر مالكها المستخدم الحالي.
- عداد المستمعين يحسب من العضويات النشطة على الخادم، ولا يثق برقم يرسله العميل.

طبّق migration `0002_profile_discovery.sql` بعد `0001_phase2_core_schema.sql` في بيئة اختبار قبل تفعيل المتغيرات على التطبيق.
