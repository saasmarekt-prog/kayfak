# حالة مشروع KAYFAK مقابل البرومبت الأصلي

## ما يعمل فعليًا في الكود

الهوية الداكنة الكحلية والذهبية، RTL، شاشة الاكتشاف، التصنيفات، غرف المعاينة المحلية، شاشة الحساب، التسجيل وتسجيل الدخول واستعادة كلمة المرور، إدارة الجلسة، قراءة وتعديل الملف الشخصي، وإنشاء غرفة كمسودة موجودة في التطبيق. توجد أيضًا دورة بيانات للغرف عبر Supabase تشمل الاكتشاف، الانضمام، المغادرة، الدعوات الخاصة، المشرفين، وإنهاء الغرفة.

أضيف مخطط Supabase للمجتمعات ومواضيعها، مع العضوية والنشر والتفاعلات وسياسات RLS. أضيفت المحفظة ودفتر القيود والهدايا والمشتريات والاشتراكات، مع idempotency ومنع الرصيد السالب وتسويات محصورة بالخادم. توجد لوحات تطبيق للمجتمعات والمحفظة والهدايا، لكنها تحتاج مشروع Supabase وبيانات حقيقية حتى تعرض محتوى فعليًا.

أضيفت Edge Functions لإصدار رمز LiveKit والتحقق من webhook وإرسال الهدايا والتحقق من Stripe webhook. التطبيق يطلب رمز LiveKit من Edge Function بعد الانضمام إلى الغرفة.

أضيف migration لمحرك القصص بالإصدارات والمشاهد والاختيارات والتقدم المحفوظ ونقاط المكافآت، مع RPC للتحقق من انتقالات العقد ومنع تكرار مكافأة الاختيار. أضيفت جولات الألعاب والإجابات والتصحيح الخادمي ومنح النقاط idempotently، وربطت الجولة النشطة بالغرفة. أضيفت واجهة القصص وواجهة الجولة داخل الغرفة.

ثُبّتت حزم `@livekit/react-native` و`@livekit/react-native-webrtc` و`livekit-client` وExpo plugins بإصدارات متوافقة مع Expo 52. أضيفت تهيئة `registerGlobals()` ومكون اتصال يدير AudioSession والميكروفون وحالة الاتصال والمشاركين.

## ما هو جزئي أو يحتاج خدمة خارجية

الاتصال الصوتي الأصلي أصبح موجودًا في كود التطبيق، لكن لم يُبنَ APK أو IPA فعلي داخل هذه الجلسة ولم يُختبر مع LiveKit server حقيقي. Expo Go غير مدعوم؛ يلزم Expo development build. كذلك لم تُنشر Edge Functions ولم تُطبق migrations على مشروع Supabase فعلي.

Stripe webhook مجهز لتسوية منتجات العملات والاشتراكات التي تأتي من Stripe فقط بعد التحقق من التوقيع. Apple App Store وGoogle Play يحتاجان adapter مستقلًا للتحقق من إيصالات المتجر وتجديد الاشتراك. لا توجد عملية شراء حقيقية مفعّلة تلقائيًا، ولا توجد بيانات دفع أو أسرار في المستودع.

## ما تبقى من النطاق الوظيفي الأصلي

محرك القصص والألعاب الأساسي موجود، لكنه يحتاج محتوى قصص وجولات فعليًا من لوحة إدارة أو seed تطويري. التصويت الاجتماعي، محرك قواعد الألعاب المتعدد الأنواع، وإدارة محتوى القصص ليست مكتملة بعد.

المتابعة بين المستخدمين، إعدادات الخصوصية الكاملة، حذف الحساب، الكتم والحظر في الواجهة، مركز البلاغات، أدوات الإشراف وسجل التدقيق، مكافحة spam وrate limits، حماية القاصرين، والاستئناف غير مكتملة.

الإشعارات الفعلية، Realtime، البحث عن المستخدمين والمجتمعات والغرف والقصص، الرسائل الخاصة، ولوحة الإدارة المنفصلة غير مكتملة. أدوات المضيف مثل طلب التحدث والموافقة، ترقية المتحدث، إزالة المشارك، الحظر داخل الغرفة، وعرض حالة المشارك تحتاج إكمالًا.

اختبارات Jest أو React Native Testing Library، اختبارات تكامل Edge Functions، اختبارات RLS ببيانات مستخدمين حقيقية، اختبارات الضغط والتزامن المالي، GitHub Actions، lint، مراقبة الأداء، النسخ الاحتياطي والاستعادة، وخطة الاستجابة للحوادث لم تُستكمل بعد.

## ما يلزم قبل اعتبار المنتج جاهزًا

يلزم ربط مشروع Supabase staging، تطبيق migrations بالترتيب، ضبط أسرار LiveKit وStripe عبر Supabase Secrets، نشر Edge Functions، تسجيل webhooks، وبناء Expo development build. بعد ذلك يجب تنفيذ اختبارات حقيقية لمستخدمين وغرف ومجتمعات وقصص وألعاب وعمليات مالية قبل أي إطلاق.

آخر فحص منفذ: `npm run typecheck` نجح، و`git diff --check` نجح، و`npx expo export --platform web` نجح، و`npx expo prebuild --no-install --clean` نجح في تطبيق plugins LiveKit. لم يتم تشغيل Supabase CLI أو PostgreSQL محليًا لعدم توفر الأدوات ومشروع Supabase مربوط.
